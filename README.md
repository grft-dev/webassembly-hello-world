# WebAssembly

This template provides a minimal setup to get AssemblyScript working in Vite.

It is the starting point for the Graftcode quick-start guide:
[Connect a WebAssembly frontend to a backend](https://github.com/grft-dev/graftcode-quick-start-guide/blob/main/1-connect-frontend-to-backend/webassembly.md).

## Getting started

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (typically [http://localhost:5173](http://localhost:5173)).
